# Interactive Dictionary

A simple command-line dictionary program built with Python as a learning project.

## Description

This program allows users to manage a custom dictionary through an interactive menu.

It was created as part of an exercise from the course **"Python 3 from Beginner to Expert - Learn Python from Scratch"** by Arkadiusz Włodarczyk (Chapter 6: Advanced Types).

The original exercise focused on dictionaries, but I extended it to practice functions and error handling.

## Features

- **Add definitions**: Store key-value pairs in your dictionary
- **Search definitions**: Look up values by their keys
- **Delete definitions**: Remove specific entries
- **View dictionary**: Display all current entries
- **Clear dictionary**: Remove all entries at once
- **Input validation**: Handles both string and integer keys/values

## How to Run

```bash
python interactive-dict.py
```

## Usage

Simply run the program and follow the menu prompts:

1. Check your dict - View all entries
2. Add new definition - Add a key-value pair
3. Search definition - Find a value by key
4. Delete definition - Remove an entry
5. Clear dict - Remove all entries
6. Exit program

## Concepts Practiced

- Python dictionaries (`.update()`, `.get()`, `.pop()`, `.clear()`)
- Functions and code organization
- Error handling with `try/except`
- User input validation
- Control flow with `match/case` statements

## Requirements

- Python 3.10+ (uses `match/case` syntax)
